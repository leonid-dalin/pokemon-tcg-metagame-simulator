# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Send a private report to [infoleonid@protonmail.com](mailto:infoleonid@protonmail.com) with:

- a clear description of the vulnerability
- the affected file, endpoint, or workflow
- reproducible steps or a proof of concept
- the impact you expect
- any proposed mitigation

Please allow time for investigation before disclosing the issue publicly. Remove credentials, personal data, and other secrets from reports.

## Scope

This policy covers the source code, API, worker, UI, Docker configuration, and repository workflows maintained here. Reports about third-party services should also identify the affected service and the boundary between this project and that service.

## Response

Reports are reviewed privately. Acknowledgement, remediation, and disclosure timing depend on severity, reproducibility, and the availability of a safe fix.

## Supported versions

Only the current default branch and the latest released version, when one exists, are supported for security fixes
